- Bake by mesh name, like Substance Painter. Name your parts Body_low / Body_high, Helmet_low / Helmet_high, then set Common parameters > Match to By mesh name. Each low poly part only takes detail from its own high poly part, so parts next to each other stop baking onto each other. The panel shows which parts found a match. The suffixes can be changed.
- "Only same mesh name" for AO (self occlusion), curvature (self intersection) and thickness (self occlusion): a part is only shaded by itself, not by the parts touching it.
- More baking settings: AO ignore backface (never / always / by mesh name with _ignorebf) and ground plane offset; Position mode (all axes or one axis) and normalization (bounding box / sphere / none); thickness min distance, spread angle, distribution; ignore backface for high poly; Restore defaults buttons. New guide page: Baking settings.
- Colours update live while you pick them: LocalPaint has its own colour picker now (the Windows colour dialog only sent the colour after OK). Editing a value only redraws the channel that changed.
- "Bake mesh maps after importing" now starts off and remembers what you choose.
